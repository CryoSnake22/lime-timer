LIME TIMER

A timer you control entirely from your keyboard.

Lime Timer is a tiny timer that floats in the corner of your Mac's screen. Start, pause, stop and edit timers from any app with a keystroke — you never have to switch windows or reach for the mouse. Hover over it only when you want to see more.

Source code on GitHub · Privacy policy

KEYBOARD SHORTCUTS

They work from any app, at any time.

⌃⌥NNew timer — type 25m focus, 1h30 deep work, 90s or 1:30, then Return. Leave it blank for a stopwatch.
⌃⌥PPause / resume
⌃⌥SStop
⌃⌥RRestart
⌃⌥EEdit the time — type a new time to restart at it, Esc to cancel
⌃⌥JKSwitch between timers
⌃⌥HHide / show
⌃⌥,Settings

SUPPORT

A shortcut doesn't work. Another app is probably using the same key combination. Quit that app (or change its shortcut) and relaunch Lime Timer.

How do I quit it? Press ⌃⌥, and choose Quit, press ⌘Q while the panel is focused, or use the timer icon in the menu bar.

Where did it go? Press ⌃⌥H to show it again. If you dragged it onto a screen that's no longer connected, it returns to the top-right corner.

Anything else: charles@chordlab.ca or open an issue on GitHub.
